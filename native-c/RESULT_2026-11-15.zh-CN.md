## 完整功能与协议

- host 完整服务 ready/PIN 两场景，覆盖 30 个 API，原生前端响应逐字节一致；合成发送及 request_id 去重、NUL/中文/emoji、>32 KiB 导入、导出/删除、换卡失效、登录/改密/单次浏览器票据均通过。通话不可用等条件按真实保护返回 409；未用假成功替代音频/呼叫。
- 2,376 组出站 PDU 精确 Go/C 差分，6,000 组固定随机入站 PDU 差分，均零差异；含 GSM7/扩展、UDH、UCS2/代理对、SCTS/时区、截断及畸形字段。
- 真实 PTY 验证无换行 `>`、长 AT 行、部分/未知提交结果、持久化保护、PIN guard、旧 call ID、不触碰数据呼叫、重启不重复提交。
- Go→C 和 C→Go 的账户文件与 NUL/UTF-8 密码、普通/remember 会话、失败回滚、改密/换卡撤销、并发单次兑换和期限边界均通过。
- host 上使用 Node 原生 HTTP2 和合成 CA 真实交换 TLS 1.2/1.3、h2/HPACK/DATA/END_STREAM；错误 CA/hostname、HTTP1 APNs、重复长度、裸 LF、RST、超限、超时均拒绝。DNS 验证 UDP TC→TCP、CNAME、压缩名和分段读取。
- ARM/Linux 3.18 中另用正式依赖实际完成 TLS 1.2/1.3 的 HTTP2 POST（310/188 ms）、完整 END_STREAM；错误 hostname/CA 在 TLS 1.2 上分别收到真实 bad_certificate(42)/unknown_ca(48) fatal alert，均未产生应用请求。独立 TLS 客户端 20 ms 采样 RSS 最高 652/660 KiB；这是测试进程观测值，不能替代完整守护程序的 TLS 峰值。
- APNs ES256 JWT 由独立 OpenSSL 校验；合成 SMS/test/VoIP 对端验证 payload、所有请求头、缓存和 200/400/403/410/429/503 分类。只在回环，未连接 Apple。
- PCM 音频真实 TCP/假 helper 完成双向 320 B 帧，单次票据、旧通话不挂新通话、64 KiB 日志和子进程清理通过。
- 旧前端 13 项测试通过。完整 C 单测和上述 host 协议/服务测试在 ASan+UBSan 下通过，未报内存或未定义行为错误。

## 审查和故障闭环

两阶段独立审查发现并修复了：重复轮询的 mutable JSON 池增长、AT 溢出/中止后仍写命令、遗留 `.tmp` 阻断保存、JSON 重复字段/大小写/null/类型语义、音频票据 wall clock，以及低内存时拨号保护/导入索引归零/流量字段的未检查分配失败。

对应故障回归均通过：长 AT 命令停止请求在 1 秒内响应；300 条记录 2,000 轮后内存池有界（重复内容 261,504→261,504 B）；关闭通道零 AT 写出；拨号保护构造失败零拨号；导入转换失败完整回滚；流量构造失败保留原 123/456 统计。已有损坏文件不会被部分 JSON 覆盖。

Linux 3.18 冷启动中，input pool 有熵仍可能未触发 secondary pool 初始化。最小 probe 证实约 60 秒 reseed 边界；C 改为非阻塞检查，只允许真实就绪的 getrandom 输出，未就绪返回错误，不以弱随机替代。实验采用显式、双后端共用的 VM 熵预检，记录真实 `getrandom_return=32`，不改 sysctl/内核或伪造熵。预检自己的 90 秒期限与测试 runtime 的原期限分别核验。

## 短信与 VPN 共存

最终 C 候选与原 16 线程 charon、既有 guard 在私有双 VM 链路通过 **30.106 秒、10 组加密 ping + 10 次短信 HTTP**；仅精确 `/32` 路由。两类流量分别计数，短信 HTTP 不被宣称走 VPN。

合成基带 polls=13、submitted=1；同身份 HTTP200，children_reaped=1。时钟先恢复再恢复监管，VPN 退出/接口与路由还原、短信服务恢复均有完成标记。采样 RSS：短信 964 KiB、charon 1,744 KiB、guard 156 KiB；CLI 观察峰值 844 KiB，系统最低 MemAvailable 26,544 KiB。

8 MiB 准入、6 MiB 绝对下限、3 MiB 最大下降、原 runtime 时限/日志/进程身份/恢复与清理要求均未放宽。内核 SHA `20080f8d7fc41a3f4483ecd982abb3541226316273e210d2a98b89100c7cc712`，guard SHA `eb5664016154d69caf5c35f26443468fbe916d6fe9d49181f2c3d5fec7566763`。
