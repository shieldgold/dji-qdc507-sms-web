# 优化短信程序与 VPN 的下一轮实机临时测试审阅方案

**尚未执行。** 电脑上的内存候选、标准回退候选、swap helper、最终 guard 和 VPN 包均已备好。完整应用、原停止条件、真实时钟/挂载回退分别通过 ARM 验证；这份文档不替代设备当天的恢复条件和新增文件操作范围确认。

## 新增动作的范围

现用程序及 `start.sh` 不覆盖，直接回退文件 `previous/smsweb` 留在模块。拟将[存储复核](STORAGE_REVIEW_2026-11-15.zh-CN.md)中两份已验证的历史副本外移到电脑保留，设备上的对应文件只在再次核对电脑副本和新鲜源身份后移除；两份历史副本不在结束时自动写回 NAND。另在本轮唯一私有 `/data/qdc-sms-RUNID/` 临时存放优化程序，以文件 bind mount 切换原执行路径。没有固件、启动文件或自启改动。

若用户不同意外移，或外移后仍不足完整候选字节数加 1 MiB，不执行复制和测试，也不删除其他文件腾空间。

## 日志、准入及顺序

1. **执行前重新核验。** 现场能切断全部供电、异常可重启；USB 位置、boot ID、内核/配置/taint、SIM READY、短信 HTTP、原监管及短信 PID/start/exe/argv、原文件及备份哈希、网络、磁盘和内存均须新鲜采集。测试证书须有效且没有被其他连接使用。不发送真实短信或拨号。
2. **采集前态并核验日志。** 先留原短信运行状态的 smaps、MemAvailable 和只读网络证据，按原三轮 30 秒方案核验 USB/kmsg 采集稳定。前态快照用于读回比较，不代替运行时停止线的基线；不清系统缓存。
3. **暂停及暂存。** 精确身份匹配的 `resume-clock ... 300` 已 READY 后才暂停原监管并终止其短信子进程。全局准入仍 12288 KiB；11776 KiB 例外仅在用户明确绑定本轮后生成，其他条件保持不变。原时钟守护的年龄、控制卡新鲜度和 180 秒入口限制仍适用。
4. **流式复制候选。** 先确认真实磁盘空间。候选可在电脑压成 gzip、按原 RAM staging 接口暂存压缩块，再 `gunzip` 管道流入固定 `copy RUNID BYTES`；禁止在 RAM 同时解包约 5.5 MB 的完整程序。复制独立 90 秒期限、6 MiB 下限和每 64 KiB 自有文件写回/回收；主机同时保留阶段日志。复制后核对原字节数/SHA、磁盘和内存，删除本轮压缩块，再暂存 VPN 文件。任何不足或错误均停止、恢复并清理。
5. **新鲜绑定后临测。** 候选、原文件、原监管和 clock guardian 身份全部匹配后，离线生成本轮 swap 和 coexist 控制卡；先 `check`，再由独立租约 `hold` 建立自己的 bind mount。运行时基线继续由原 guard 在**暂存完成、短信仍暂停、LOGGER_READY/GO 前**采集（`guard.c` 原取样位置不动），不能改成优化短信启动后的值。没有 SWAP_READY、LOGGER_READY 或 GO，不启动 VPN。保留原 8192 KiB 启动、6144 KiB 绝对下限、3072 KiB 最大下降、30 秒/10 组、80+3 秒期限、日志异常停止和 1 MiB 日志上限。
6. **先恢复短信，再删除时钟证明。** VPN 窗口结束或中止后，保留 `/run/qdc-tun-RUNID/sms-guard.log` 和原 guardian 目录；先精确终止本轮 swap 租约，让它停止优化短信子进程、普通卸载自有 mount、重验原文件、通过 SIGUSR1 或既有 SENT 取得时钟证明，再 CONT 原监管。只有 SWAP_COMPLETE 后才进入旧 VPN 包最终 RAM 目录清理。不能先删除旧包的 clock 日志，否则 helper 会拒绝恢复。
7. **独立读回验收。** 原 f34 程序及启动脚本哈希、原 SUP PID/start、单一原程序子进程、HTTP 200、SIM、boot/taint/配置和网络应与预期一致；VPN 无进程/SA、地址/路由/接口已复原。确认 TUN 引用为零才普通卸载，不强制卸载。再取回日志、核对清单，清理本轮 RAM 文件及自有候选目录。

## 停止、恢复及证据

内存/存储不足、身份或哈希变化、未知挂载、USB/kmsg 异常、时钟证明失败或期限越界均停止。挂载工具最多在原 guardian 年龄 270 秒进入回滚，预留 30 秒；它不重借一轮 300 秒。未知资源保留，RECOVERY_REQUIRED 时不以 CONT 掩盖失败。若现场硬锁，按已确认的完整断电/异常重启条件恢复；重新连接后核对原程序，再仅清理清单内已确认的残留。

记录只含时间、状态、字节数、资源指标、PID/start、inode/mount 和哈希；不采短信正文、PIN、登录 token 或私钥。完整阶段日志、构建/证据摘要与原始采样留电脑私有目录。实机成功须满足完整业务窗口与恢复读回，不能用编译成功、握手成功或若干组成功代替。
