# QDC507 专用证书实机连接验证

用户授权使用既有“创建routeros 证书”会话创建或选择未连接的证书进行测试。服务器侧由该会话增量签发专用短期 RSA 证书、只部署公开证书与新测试 /32 的最小访问规则；不得轮换 CA、复用其他设备私钥或改变共享 peer/算法。

模块缺少 veth/macvlan、没有蜂窝默认路由。采用主网络中一个临时 ipsec0 和仅至测试目标的 /32 路由，保留既有默认路由/DNS/地址；新 peer 指向 Mac USB 地址的受限 UDP 中继。中继只在模块与选定 IKE 服务器之间转发：将初始 IKE_SA_INIT 去除非 ESP 标记送 UDP/500，后续原样送 UDP/4500。Mac 使用已连接 UDP socket 和 NAT keepalive 发起流量，不修改主机防火墙或路由。此测试不等同于 4G 出网验收。

短信应用以系统时间判断登录有效期，因此采用独立 resume-clock 守护：先保存原实时时钟/单调时钟，再暂停原短信循环、临时校时；结束/超时先恢复原时钟加单调经过时间，再 CONT 原循环。只在 RAM 中暂存客户端、配置、证书与私钥，不输出秘密，不写启动或 RTC 配置。
