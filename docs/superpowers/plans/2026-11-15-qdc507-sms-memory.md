# QDC507 短信内存优化与功能保持

用户要求在保障功能前提下尽可能降低短信与 VPN 共存的资源开销。当前工作在独立 worktree/分支进行；保留模块原短信程序，先完成电脑与隔离 ARM 验证。

## 约束与验收

- 保留短信收发、分片/PDU、提示符、URC、PIN/SIM 绑定、认证、推送、通话、备份恢复及原有轮询频率。
- 不降低密码/证书/协议安全，不关闭业务服务腾内存，不改变内存基线取样位置。
- 实机启动至少 8192 KiB，运行至少 6144 KiB，较原始基线下降不得超过 3072 KiB；其他日志/身份/期限停止条件不变。不刷机、不设置自启。
- 先用部署相同的 Go 1.23.12 和编译参数固定 before/after；区分分配流量、GC 堆及 RSS/PSS/系统可用内存，不把电脑基准当实机证明。
- 每项优化先复现性能或行为失败，测试覆盖既有语义，再最小修改。只保留有测量收益且通过回归的变更。
