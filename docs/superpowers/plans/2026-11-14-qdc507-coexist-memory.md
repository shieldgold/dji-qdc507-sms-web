# QDC507 短信与 VPN 共存内存优化

范围：仅调整临时测试工具，不修改生产短信程序、监管脚本、固件或启动配置。

- [x] 根据 D03B 原始日志分离短信堆增长与测试子进程峰值。
- [x] HTTP、单次 ICMP 改为 guard 内的非阻塞探测，轮询不超过 100 ms；等待期间继续原有内存、内核日志与进程身份检查。
- [x] smaps 改为小缓冲流式统计，保持读取到 EOF、128 KiB 输入上限和错误拒绝规则。
- [x] 新旧版本在相同 ARM 实验环境比较；新版本通过 20 项运行时回归及 7 项共存实验，生成匹配二进制的回执。
- [x] 核验 USB、SIM、蜂窝、证书、原短信监管与内存，执行一轮受控临时测试。
- [x] 验证恢复、清理和原有网络/启动文件一致，记录结果。
- [x] 完成提交推送所需的代码、证据及报告整理；存档状态以当前分支提交和远端摘要核验为准。

停止规则不变：启动后可用内存不得低于 6144 KiB，较原始基线下降不得超过 3072 KiB；暂存后启动至少 8192 KiB；日志异常、身份改变及超时立即停止。共存 30 秒、10 对 ICMP/HTTP，80 秒硬期限及 3 秒强制终止后备。原始基线采样位置不变，16 个 charon 工作线程暂不调整。
